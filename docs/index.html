YicesTRA

A solver for real arithmetic with transcendental functions

GitHub Example Usage Installation Paper People Contribute

YicesTRA is a tool to decide the satisfiability of quantifier-free formulas of non-linear real arithmetic extended with transcendental functions. The current version supports the sine function sin, the exponential function exp, and the constant pi. The tool is an extension of the Yices 2 SMT solver. The source code is available here under the GPLv3 license.

YicesTRA has two modes. By default it looks for an exact answer and only reports sat or unsat. When a tolerance δ is fixed by the user with the option --mcsat-delta (see below), the solver additionally reports delta-sat, and stops as soon as an assignment satisfies the formula up to δ.

Examples

Consider the following formula, which asks for a real number in the interval [0, π/2] whose sine has a square larger than 1/2 and whose exponential is smaller than 3:

∃x ∈ [0, π/2].   sin(x)2 > 1/2  ∧  exp(x) < 3

Encoding the formula

YicesTRA reads the SMT-LIB 2 format. The formula above is encoded as follows (intro.smt2): 

(set-logic QF_TRA)
(declare-fun x () Real)
(assert (<= 0 x))
(assert (<= x (* (/ 1 2) pi)))
(assert (> (* (sin x) (sin x)) (/ 1 2)))
(assert (< (exp x) 3))
(check-sat)
(get-model)

The logic QF_TRA tells the solver that the formula belongs to transcendental real arithmetic. Within this logic the symbols sin, exp and pi are predefined and must not be declared. Everything else is standard SMT-LIB 2.

Solving the formula

We run the solver on the file: 

$ ytra intro.smt2
    sat
    ((define-fun x () Real 1.0))

The solver answers sat. Because the instance contains (get-model), the solver also returns a model: x = 1. This is indeed a solution, since sin(1)2 ≈ 0.708 > 1/2 and exp(1) ≈ 2.718 < 3.

An unsatisfiable formula

The exponential function lies above its tangent line at 0, so the constraint exp(x) < 1 + x has no solution (exp-tangent.smt2): 

(set-logic QF_TRA)
(declare-fun x () Real)
(assert (< (exp x) (+ 1 x)))
(check-sat)
$ ytra exp-tangent.smt2
    unsat

An unsat answer is a proof that the formula has no real solution.

A δ-satisfiable formula

The equation sin(x) = 1/2 has exactly one solution in the interval [0, 2], namely x = π/6. This number is transcendental, whereas YicesTRA (for the moment!) only computes algebraic values. It therefore cannot answer sat nor unsat. Run without options, the solver keeps approximating π/6 to higher precisions until the time limit is reached (sin-half.smt2): 

(set-logic QF_TRA)
(declare-fun x () Real)
(assert (<= 0 x))
(assert (<= x 2))
(assert (= (sin x) (/ 1 2)))
(check-sat)
(get-model)

To obtain an answer, we fix a tolerance with the option --mcsat-delta=D, which sets δ = 2−D and enables the third answer, delta-sat. Here we take D = 10, so that δ ≈ 10−3: 

$ ytra --mcsat-delta=10 sin-half.smt2
    delta-sat (with delta 10)
    ((define-fun x () Real (/ 36844988291815 70368744177664)))

The returned value x = 36844988291815 / 70368744177664 ≈ 0.5235987755983018 differs from π/6 by less than 3·10−15. Formally, a delta-sat answer means that the assignment satisfies the δ-weakening of the formula, obtained by relaxing every atom that involves a transcendental function by δ. For instance, the δ-weakening of the atom sin(x) = 1/2 is |sin(x) − 1/2| ≤ δ. Note, however, that YicesTRA does not internally relax any atomic formula, and in particular it will never return delta-sat on an instance with no transcendental functions.

Usage

Input format

  • The file must start with (set-logic QF_TRA). This logic predefines the unary functions sin and exp (of type Real → Real) and the constant pi. These functions must not be declared by the user.
  • The remaining constructs are those of SMT-LIB 2 for real arithmetic: declare-fun and declare-const for variables of sort Real and Bool, the arithmetic operations +, -, * and /, the predicates <, <=, >, >=, =, the Boolean connectives, ite and let, and the commands assert, check-sat, get-model and get-value.
  • Rational constants can be written as decimals, such as 0.5, or as fractions, such as (/ 1 2).
  • Other transcendental functions are not built in (for now!). Trigonometric functions can be expressed with sin and pi, for instance (cos x) can be written as (sin (+ x (* (/ 1 2) pi))).

Command line

$ ytra [options] file.smt2
OptionMeaning
--mcsat-delta=D Fixes the tolerance to δ = 2−D, for a positive integer D, and enables the answer delta-sat. Larger values of D make the answer more precise. Without this option the solver only answers sat or unsat.
--dump-models Prints a model after every sat or delta-sat answer, without a (get-model) command in the input file.
--mcsat-help List options of the MCSAT engine.
--help List further options inherited from Yices.

Installation

YicesTRA requires:

  • gperf and GMP, as for Yices 2;
  • libpoly and CUDD (configured with --enable-shared), as for the MCSAT engine of Yices 2;
  • FLINT, version 3 or later (it includes the Arb module), and MPFR.

Once the dependencies are installed, build the tool with:

$ git clone https://github.com/arith-lab/yices-tra.git
$ cd yices-tra
$ autoconf
$ ./configure
$ make

The binary is placed in build/<platform>-release/bin/ytra, for instance build/x86_64-pc-linux-gnu-release/bin/ytra on Linux. If configure does not find a library, pass its location with CPPFLAGS and LDFLAGS. The README on GitHub contains further troubleshooting notes.

How it works

YicesTRA implements an extension of the procedure described in the paper MCSAT Modulo Transcendental Arithmetics. The procedure works within MCSAT, the model-constructing satisfiability calculus of Yices 2, and is built around a new theory plugin, the TRA plugin, that acts as an intermediary between the core MCSAT solver and the existing plugin for non-linear real arithmetic (NRA).

Non-total functions

Unlike the version described in the paper, the implementation also supports non-total functions. Currently, the only such function is division /, which is undefined when the denominator is zero. The SMT-LIB standard specifies that (/ t1 t2) behaves as an uninterpreted function whenever t2 is 0.

Respecting this semantics requires deciding whether a term is zero, which is a hard problem in transcendental arithmetic: even for variable-free terms, no general decision procedure is known, and the known decidability results rely on Schanuel's conjecture. YicesTRA therefore uses a δ-relaxed semantics. When evaluating (/ t1 t2), if the tool cannot decide whether t2 = 0 using a precision that depends on δ, it treats t2 as zero and allows any value for (/ t1 t2). If a solution is found under the δ-relaxed semantics, the tool reports delta-sat when --mcsat-delta is given, and otherwise continues the search.

Under the δ-relaxed semantics, sat and unsat answers respects the SMT-LIB semantics.
